# Repository research decisions

Checked public upstream sources October 29, 2026. These are candidates/references, not installed dependencies or a claim of completed integration. Existing approved design remains authoritative.

| Repository | Useful contribution | License / limits | Decision |
|---|---|---|---|
| [Adobe React Spectrum / React Aria](https://github.com/adobe/react-spectrum) | Unstyled accessible select, dialog, focus and internationalization patterns for web filters | Apache-2.0; inspect exact selected package/version, dependency/security and Next/React compatibility before use | Prefer existing semantic native HTML first. Consider React Aria only if a complex control needs it; do not import Adobe's entire visual system. |
| [TanStack Virtual](https://github.com/TanStack/virtual) | Bounded DOM rendering for genuinely large unpaginated lists | MIT; React adapter only, dynamic-size/focus/screen-reader handling needs testing | Current web pagination/search worker already bounds work. Defer installation unless measured list performance warrants it. Native LazyColumn/List remain native. |
| [Motion](https://github.com/motiondivision/motion) | Interruption-safe interaction/layout animation patterns | Open-source core MIT; Motion+ is a separate paid offering | Existing original loader and small CSS interactions suffice for parity. No paid offering or needless new runtime. |
| [Open Referral HSDS](https://github.com/openreferral/specification) | Separates organizations, services, eligibility and locations instead of treating everything as a dated event | Current specification/docs CC BY-SA; older versions CC0. It is a schema, not a free catalogue of volunteer roles | Study modelling principles. Do not copy/relicense schema files or migrate the feed wholesale without a separate compatibility/licence review. |
| [Hack Club](https://github.com/hackclub/hackclub) | Original teen-facing tone, practical projects and open learning resources | Root repository says code MIT and content CC BY-SA. Other repos have their own licences; do not assume site/brand/photos share this licence | Public product-flow reference and potential source links. Do not copy branding/art or treat all linked programs as verified free/eligible. |
| [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | Already-installed UX design checks across web, SwiftUI and Compose | Existing local skill; this task does not authorize a competing agent runner or bulk workflow installation | Used the installed design search, while preserving approved Nunito and GTA tokens instead of accepting a replacement generated palette. |
| [Helfertool](https://github.com/helfertool/helfertool) | Volunteer/staff management reference identified through connected GitHub repository search | AGPL-3.0; non-archived, last pushed September 19, 2026 in the inspected repository metadata | Not selected as a dependency: event-staff administration is a different job from public teen discovery, and importing a separate hosted service adds operational/licensing scope. |

Public reference findings come from [Volunteer Toronto](https://www.volunteertoronto.ca/page/HighSchoolVolunteers), [Volunteer Success](https://www.volunteersuccess.com/opportunities) and official provider/education pages listed in recon.md. Their listings/photographs are not reusable merely because the sites are public. A dependency can improve controls or performance; it cannot guarantee fresh roles, school approval, complete geography or top search ranking.

The live 21st.dev reference check is part of frontend's current web parity work. No 21st component is approved by this research document alone.

Connected GitHub metadata independently confirmed non-archived upstreams and recent pushes for React Spectrum (October 29), TanStack Virtual (October 29) and Motion (October 29). These are point-in-time maintenance signals, not a security audit, a pinned compatible package review or permission to install them. No new dependency was needed for the web named-filter storage implementation.
