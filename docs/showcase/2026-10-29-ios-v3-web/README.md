# Website matches the approved iOS visual system

October 29, 2026. These are unretouched browser screenshots of the final local production export, bound to application source `5f0792e1781922e9f9b981f7d151a6d3b1ee4b66`. They are product evidence, not mockups or public-deployment proof. [Capture receipt](capture-receipt.json).

The site uses self-hosted Nunito, original GTA illustrations, cool opaque light/dark surfaces, a topic-led Home and named saved filters inside Browse. The original logo animation and map-first discovery remain. Selecting a filter immediately applies it; Save/Update is explicit. Saves stay in the current browser.
